Digital Banking Backend

Backend d'une application de gestion de comptes bancaires, développée avec Spring Boot et Spring Data JPA.

L'application permet de gérer les clients, les comptes bancaires et les opérations bancaires de type CREDIT et DEBIT.

Description du projet

L'objectif de ce projet est de développer une application complète de Digital Banking permettant :

La gestion des clients
La gestion des comptes bancaires
La gestion des opérations bancaires
La gestion de deux types de comptes :
Compte courant
Compte épargne
La consultation de l'historique des opérations
L'exposition des fonctionnalités via des REST APIs
La documentation des APIs avec Swagger / OpenAPI

Le projet est développé suivant une architecture en couches afin de séparer les responsabilités entre les différentes parties de l'application.
